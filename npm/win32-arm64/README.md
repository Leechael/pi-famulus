# pi-famulus-win32-arm64

The Windows arm64 native manager for `pi-famulus` (`aarch64-pc-windows-msvc`).

This package is **not** part of the required release set and is not an optional dependency of `pi-famulus`. CI does not build it (publish downloads only the current run's artifacts). It stays in the tree so a producer can be added later; do not publish it until that build exists.

Install `pi-famulus`, not this package directly. See the [project](https://github.com/Leechael/pi-famulus#readme).
